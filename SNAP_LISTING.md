## Description

```markdown
Pin keeps your ranked priorities on top of every window.

- Rank tasks by dragging them; the top line matters most.
- Color each task from twelve colors or any custom color.
- Add subtasks with one click (or Ctrl+T) and dates with Ctrl+D.
- Delete with the trash icon; Ctrl+Z undoes anything.
- Unpin it with one click when you need the space.
- Your list is a plain Markdown file in your Documents folder, readable by any notes app.
```
